# Speakeasy's direct dependencies, pinned to exact versions.
#
# The "==" means "install THIS version, never a newer one." This protects you
# from a supply-chain attack: if a bad actor ever slips malicious code into a
# future release of one of these libraries, you won't silently pull it in the
# next time you reinstall. These libraries are powerful (the Quartz event tap
# sees every keystroke), so locking them matters.
#
# Keyboard listening (hotkey), the synthesized ⌘V paste, the clipboard, and
# all UI go through Apple's own frameworks via the pyobjc wrappers below —
# no third-party input library. (pynput was removed: its macOS backend
# crashes the process once the app shows a text field.)
#
# To update deliberately later: bump the version below, reinstall, test that
# dictation still works, then regenerate the full lock file with:
#   .venv/bin/pip freeze > requirements.lock.txt
#
# For an exact reproduction of the complete tested environment (these PLUS
# every helper library they depend on), install from requirements.lock.txt.
